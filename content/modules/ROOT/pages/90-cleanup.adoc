== Remove what you created

These steps remove the OpenShell release, its namespace, the Keycloak user and client, and the chart
repository. ZTVP and the Web Terminal stay.

WARNING: Deleting the namespace removes everything in `{lab_namespace}`, including the sandbox and any code Pi wrote.

[source,bash,role="execute",subs="attributes+"]
----
openshell gateway remove ztm-demo 2>/dev/null
helm uninstall {release_name} -n {lab_namespace} --wait --timeout 5m
oc delete namespace {lab_namespace} --wait=true --timeout=180s
KEYCLOAK_URL=https://$(oc get route -n keycloak-system -o jsonpath='{.items[0].spec.host}')
ADMIN_PASSWORD=$(oc get secret keycloak-admin-user -n keycloak-system -o jsonpath='{.data.password}' | base64 -d)
ADMIN_TOKEN=$(curl -sk "$KEYCLOAK_URL/realms/master/protocol/openid-connect/token" -d client_id=admin-cli -d username=admin --data-urlencode "password=$ADMIN_PASSWORD" -d grant_type=password | jq -r .access_token)
for path in "users?username=demo-engineer&exact=true" "clients?clientId=openshell-gateway"; do
  id=$(curl -sk "$KEYCLOAK_URL/admin/realms/{keycloak_realm}/$path" -H "Authorization: Bearer $ADMIN_TOKEN" | jq -r '.[0].id // empty')
  [ -n "$id" ] && curl -sk -o /dev/null -w "delete ${path%%\?*}: HTTP %\{http_code}\n" -X DELETE "$KEYCLOAK_URL/admin/realms/{keycloak_realm}/${path%%\?*}/$id" -H "Authorization: Bearer $ADMIN_TOKEN"
done
oc delete helmchartrepository openshell-ztm-demo --ignore-not-found
----

Expected result: `release "{release_name}" uninstalled`, `namespace "{lab_namespace}" deleted`,
`delete users: HTTP 204`, `delete clients: HTTP 204`, and the chart repository `deleted`.

Check what is left:

[source,bash,role="execute",subs="attributes+"]
----
oc get namespace {lab_namespace}
oc get crd sandboxes.agents.x-k8s.io -o name
----

Expected result: `namespaces "{lab_namespace}" not found`, and the CRD
`customresourcedefinition.apiextensions.k8s.io/sandboxes.agents.x-k8s.io` still listed. The chart installs that
cluster-scoped CRD and Helm does not remove CRDs. Leave it unless the cluster owner asks; deleting a CRD deletes
every object of that kind. The MaaS key also stays in Vault at `secret/hub/infra/openshell/maas`, where the next
install overwrites it.

== Remove the lab environment (whoever deployed it)

Only the person who ran the bootstrap removes the environment. From a cluster-admin shell in a checkout of
this repository, first look at what the teardown will delete:

[source,bash,subs="attributes+"]
----
make -C automation status
oc get namespace {showroom_namespace}
----

Then delete it and confirm the namespace is gone:

[source,bash,subs="attributes+"]
----
make -C automation teardown
oc get namespace {showroom_namespace}
----

The last command reports `NotFound` once deletion completes. The facilitator prerequisites (Web Terminal operator,
participant user, Vault role) and ZTVP itself stay; see xref:92-facilitator-guide.adoc[Facilitator Guide] to remove them.
