OpenShift에서 자율형 AI 코딩 에이전트를 실행한 다음, 그 에이전트가 할 수 없는 일을 직접 증명합니다.

link:https://pi.dev/[Pi^]와 같은 AI 코딩 에이전트는 스스로 코드를 작성하고, 패키지를 설치하고, API를 호출하고,
프로그램을 실행합니다. 따라서 제약이 없는 에이전트는 소스 코드를 임의의 서버로 보내거나, 컨테이너 안의 모든 파일을
읽거나, 전달받은 LLM API 키를 유출할 수 있습니다. 이 랩에서는 Red Hat Zero Trust Validated Pattern(ZTVP)이
이미 실행 중인 클러스터에서 NVIDIA OpenShell 샌드박스 안에 Pi 에이전트를 실행하고, 각 제한 사항을 그대로 믿는 대신
직접 검증하도록 합니다.

랩은 다음 작업 순서로 진행됩니다.

. OpenShell의 Helm 차트를 Developer Catalog에 등록하고 설치합니다. API 키는 Vault에 저장하며 공개 엔드포인트는 두지 않습니다.
. OpenShell CLI를 게이트웨이에 연결합니다.
. Pi가 Red Hat MaaS LLM을 통해 코드를 작성하고 실행하는 과정을 확인합니다.
. 샌드박스가 승인된 세 개의 호스트에만 접속할 수 있음을 증명합니다.
. Linux 커널(Landlock)이 에이전트가 쓸 수 있는 경로를 제한함을 증명합니다.
. 실제 API 키가 샌드박스에 절대 들어가지 않음을 증명합니다.
. Vault, External Secrets, SPIRE, ACS, Keycloak이 OpenShell과 어떻게 연결되는지 추적합니다.
. 게이트웨이의 OIDC 클라이언트용 Keycloak 토큰을 발급받습니다.
. 실행 중인 샌드박스의 네트워크 정책을 변경한 다음, 그 변경을 철회합니다.

== 학습 목표

랩을 마치면 다음을 할 수 있습니다.

* Developer Catalog에 등록된 Helm 차트 리포지토리에서 OpenShell을 OpenShift에 배포하고, 클러스터 내부에서만 접근할 수 있도록 구성합니다.
* 에이전트 샌드박스에서 허용된 egress와 거부된 egress를 시연하고, 거부가 즉시 이루어지는 이유를 설명합니다.
* root 사용자가 일반적으로 쓸 수 있는 경로를 포함하여, 컨테이너 내부에서 Landlock 파일 시스템 강제 적용을 시연합니다.
* 리졸버 토큰이 실제 LLM 자격 증명을 샌드박스 밖에 두는 방식을 설명합니다.
* 차트가 구성하는 Vault 경로, ExternalSecret, ClusterSPIFFEID, Keycloak 클라이언트를 찾습니다.
* 샌드박스 네트워크 정책을 실시간으로 업데이트하고 변경 사항을 확인한 다음, 원래대로 되돌립니다.

== 랩 진행 방법

각 실습에서는 변경할 상태, 확인할 증거, 그리고 검증해야 할 결과를
제시합니다. 명령이 완료되었다는 사실을 증거로 취급하지 마십시오.
다음 단계로 넘어가기 전에 관찰한 리소스, 정책 또는 이벤트를 제시된 예상
결과와 비교하십시오. 진행자는
xref:modules::92-facilitator-guide.adoc[진행자 가이드(영어)]를 참조하십시오.

모든 모듈과 Web Terminal 설정에는 이 가이드 전체를 실행하는 동안 랩 클러스터에서 녹화한 짧은 동영상이
포함되어 있습니다. 배너에 각 실습 이름이 표시되고, 노란색 상자는 결과를 증명하는 출력을 표시하며, 명령이 끝나기를
기다리는 구간은 빠르게 재생됩니다(*sped up* 표시). 단계를 실행하기 전에 미리 보거나, 자신의 출력이 다를 때 비교하려면
동영상을 시청하십시오. LLM 출력(모듈 3)과 생성된 이름 및 타임스탬프는 여러분의 결과와 다릅니다.

== 기술 모델

* **OpenShift**는 모든 구성 요소를 실행하며 Developer Catalog, Route, Web Terminal을 제공합니다.
* **ZTVP**는 공유 보안 서비스를 제공합니다. Vault(시크릿), External Secrets Operator(시크릿 동기화),
  Keycloak(사용자 ID), SPIFFE/SPIRE(워크로드 ID), Advanced Cluster Security(이미지 및 런타임 정책)입니다.
* **OpenShell**은 게이트웨이, 에이전트와 네트워크 사이에 위치하는 수퍼바이저, 그리고 정책 엔진을 추가합니다.
* Linux 커널 보안 모듈인 **Landlock**은 샌드박스 파일 시스템 정책을 강제 적용합니다.
* **Pi**는 테스트 대상 에이전트이며, *Red Hat MaaS*(Model-as-a-Service)는 Pi가 호출하는 LLM입니다.

어느 한 계층만으로는 충분하지 않습니다. Kubernetes NetworkPolicy는 프로세스 단위가 아니라 파드 단위로 동작합니다.
Vault는 시크릿을 암호화하여 보관하지만, 읽을 권한이 있는 대상에게는 그대로 넘겨줍니다. 컨테이너 파일 시스템은
root에 대해 아무것도 제한하지 않습니다. OpenShell의 바이너리별 egress 규칙, Landlock, 경계 측 자격 증명 해석(resolution)이
이러한 공백을 메우며, ZTVP는 OpenShell이 사용하는 ID와 시크릿을 제공합니다.
